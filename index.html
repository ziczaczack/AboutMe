Trade Journal

A full-stack journal for traders: import trades from CSV, write up each trading day, tag mistakes and see what they cost, and track performance with an analytics dashboard, calendar heat map and setup playbooks.

Supabase runs the Postgres database (with row-level security), auth and screenshot storage. Every push goes through lint, type-check, tests and a build in GitHub Actions before it ships to Vercel.

Next.js · React · TypeScript · Tailwind CSS · Supabase · Vitest
